# 🚗 Smart Vehicle Monitoring and Parent Alert System

## Overview

The Smart Vehicle Monitoring and Parent Alert System is a Python-based software simulation project designed to monitor vehicle driving behavior in real time.

The system simulates vehicle movement, detects speed limit violations, stores driving data in an SQLite database, generates alerts, and generates statistical reports to evaluate driver safety.

This project was developed as a personal portfolio project and is intended to evolve into a future research project by incorporating Machine Learning techniques for dangerous driving prediction.

---

## Features

- Vehicle speed simulation
- Real-time speed monitoring
- Automatic speed limit alerts
- SQLite database integration
- Alert history storage
- Driver Safety Score calculation
- Statistical reports
- Dashboard interface
